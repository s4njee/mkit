# E8 progress audit — 2026-09-27

E8 is underway, not complete. The registry has `implementation_in_progress` drafts for Viewport, PrecisionSlider, CurveEditor, ColourTools, GradientEditor, Histogram, PropertyInspector, LayerPanel, CommandPalette, ShortcutEditor, Timeline, and NodeEditor alongside the ScrubbableNumberField pilot. Timeline and node editor have [T1–T4](E8_TIMELINE_SPLIT.md) and [N1–N4](E8_NODE_EDITOR_SPLIT.md) story splits. All four slices of each are implemented as drafts; public contracts and full conformance remain open.

The [maintainer review handoff](E8_REVIEW_HANDOFF.md) collects the API, spec, baseline, book, and native-platform decisions that still need human judgment.
