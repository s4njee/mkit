# E4.1 theme token foundation

`mkit-core::theme` defines semantic color roles, a typography scale, spacing,
radii, border widths, shadow recipes, and motion durations. Dimensions are
logical pixel values; typography values are sizes only because font family
selection belongs to the host application. `Theme` implements GPUI's `Global`
marker and the `set_theme` helper stores a complete theme then calls
`App::refresh_windows`, the GPUI 0.3.5 API that schedules all windows to redraw.
The `LIGHT`, `DARK`, and `HIGH_CONTRAST` constants are the built-in palettes.

The theme is copied by value and read with `app.global::<Theme>()`. Components
should use semantic fields (for example, `theme.colors.focus`) rather than
introducing their own color constants. Animation helpers can read
`theme.motion.{instant,fast,normal,slow}_ms`; callers should still honor GPUI's
`App::reduce_motion()` preference when choosing whether to animate.

The module tests built-in palette differences and GPUI global replacement. A
headless two-window test renders views that read the global theme, switches to
dark, and checks that both views render again with the new value. The `none`
shadow uses explicit RGBA encoding so its color remains transparent black in
every built-in theme.

`cargo test -p mkit-core --locked` passed the core suite including the
two-window redraw assertion. `cargo clippy -p mkit-core --all-targets --locked
-- -D warnings` also passed in the first E4 pass. The redraw helper uses GPUI
0.3.5 `App::refresh_windows`; the headless test confirms both open windows
render again and read the replacement theme.

## Visual matrix

The E4.6 rendered toggle example consumes the theme global. Its macOS Metal
headless screenshot target now compares light, dark, and high-contrast initial
states at 640 × 400 logical pixels and scale 1.0, plus light at scale 2.0.
All four baselines were visually inspected and
`cargo test -p mkit-example-state-entities --test component_state_screenshot
--locked` passed. This verifies token consumption and rendering at those states;
it does not prove accessibility contrast ratios or automatic OS theme
switching. A live accessibility snapshot remains pending.
