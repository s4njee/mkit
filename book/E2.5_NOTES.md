## Source cautions

- `Context::notify` is explicit for the changed entity. `Entity::write` calls it, but a generic `Entity::update` closure does not do so automatically; examples must notify when a displayed value changes. [Source](https://github.com/zed-industries/zed/blob/d89e9c2124b2786a390c7a451c7488601b4da2e1/crates/gpui/src/app/entity_map.rs#L476-L503).
- `Context::subscribe` constrains its emitter to `EventEmitter<Evt>`; `Context::emit` has the same bound. An observer is for `notify`, not for typed event payloads. [Source](https://github.com/zed-industries/zed/blob/d89e9c2124b2786a390c7a451c7488601b4da2e1/crates/gpui/src/app/context.rs#L99-L115).
- `Subscription` has `#[must_use]` and dropping it cancels the callback. Store it in the owning view or explicitly detach with the lifetime consequences documented. [Source](https://github.com/zed-industries/zed/blob/d89e9c2124b2786a390c7a451c7488601b4da2e1/crates/gpui/src/subscription.rs#L147-L169).
- The GPUI [published guide](https://docs.rs/crate/gpui-pre/0.3.5) is for this exact package. Newer Zed `main` snippets may name APIs absent from this pin; keep every chapter include tied to a compiling pinned example.
