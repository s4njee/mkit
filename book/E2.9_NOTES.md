# E2.9 custom rendering evidence

Status: seven chapters are published under `book/src/custom-rendering/` from compiling `examples/custom_rendering` anchors. The workspace pins `gpui-pre = 0.3.5` at Zed commit [`d89e9c2124b2786a390c7a451c7488601b4da2e1`](https://github.com/zed-industries/zed/tree/d89e9c2124b2786a390c7a451c7488601b4da2e1). Six library tests check element phase order, pan/zoom math and input, anchored overlay bounds and hit routing, visible list slices, easing, and one-shot reduced motion. Seven inspected 640 × 480, scale-1 macOS baselines cover canvas states, overlays, both list forms, the reduced-motion endpoint, and a pixel-asserted CoreVideo surface. The current headless pixel renderer is macOS-only; see [E1 evidence](../docs/spikes/headless.md).

## Fixture and review limits

The final anchors are `custom_element`, `canvas_primitives`, `overlay_layers`, `virtualized_lists`, `animation_motion`, `surface_macos`, `pan_zoom_view`, and `pan_zoom_main`. Chapter Rust fences contain only mdBook anchored includes. The screenshot test uses literal paths under `book/src/images/` and a checked-in PNG fixture. MacOS baselines show the overlay stack and popover, visible slices from both list types, the reduced-motion animation endpoint, and the 128-pixel CoreVideo surface. The overlay baseline verifies draw order; its library test verifies in-window bounds and shows that a click on the overlapping region reaches the lower painted layer. It does not test every viewport edge. The animation test checks easing at 0.5 and the one-shot reduced-motion end state; it does not measure frame timing. The surface capture checks visible pixels, while its non-macOS fallback is source-audited rather than cross-compiled here. No relevant official Zed issue was verified for these narrow helpers, so chapter Common mistakes sections were omitted under `book/STYLE.md`.

Request maintainer review of public API claims, custom-element accessibility, interaction math, visual baselines, and platform GPU limits. The overlay and surface rows are checked for their narrow test and capture evidence; native GPU interoperability beyond this CVPixelBuffer path remains unproven.
