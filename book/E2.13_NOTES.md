# E2.13 cookbook evidence matrix

Status: `examples/cookbook/src/lib.rs` contains 40 named `recipe_*` anchors, including `recipe_scroll_view`, nested `recipe_drag_reorder_ui`, and `recipe_restore_window_size`. This matrix records the implementation visible on 2026-09-24. Thirty-two recipe pages are published under `book/src/cookbook/` and listed in `SUMMARY.md`. The first E2.13 plan box is complete; the evaluation-request box remains open. A named anchor alone is not a verified recipe. Each page has an accurate title, an anchored mdBook include, an exact command, bounded evidence for the stated behavior, and a harness screenshot when the behavior renders. The macOS screenshot harness compares six 960 × 640 baselines: `cookbook.png`, `cookbook-dark.png`, `cookbook-scrolled.png`, `cookbook-dragged.png`, `cookbook-counter.png`, and `cookbook-modal.png`. A foreground-pixel guard rejects blank captures. Each image supports only the state it shows.

Evidence labels: **tested** means a current test directly asserts the claim; **view tested** means a rendered GPUI interaction is exercised; **source only** means the anchor compiles but has no focused behavior check yet; **native manual** means the platform behavior was not established by the headless fixture. All anchors below are in `examples/cookbook/src/lib.rs` unless stated otherwise. The 32 published pages use 33 of the 40 anchors; `recipe_scroll_view` is paired with `recipe_scroll_region` on one page.
