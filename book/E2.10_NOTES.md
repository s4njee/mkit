## Verification and remaining limits

On 2026-09-24, `cargo test -p mkit-example-async-file-browser -p mkit-example-async-persistence --locked` exited successfully: five browser library tests, two SQLite adapter tests, and the browser screenshot target. The browser screenshot source compares [loading](src/images/async-file-browser-loading.png), [loaded](src/images/async-file-browser-loaded.png), and [error](src/images/async-file-browser-error.png) baselines on macOS; the pinned headless renderer reports unsupported capture on Windows and Linux. `python3 scripts/check_book.py`, `mdbook build book`, and `python3 scripts/check_book.py --skip-cargo --built-html` verify anchors and published links.

Native file permissions across OSes, live directory races, and a browser-to-SQLite integration are outside the tested fixture. The SQLite adapter is synchronous; a GPUI app should run blocking database work away from the UI thread. Public API and book claims, the persistence contract, and visual baselines still need maintainer judgment under `AGENTS.md`; those review responsibilities do not make the documented local tests incomplete.
