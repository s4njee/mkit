# E2.6 pinned-source audit and chapter map

Status: source audit and chapter map. The six E2.6 chapters now use anchors from the compiling settings-screen crate and its top and scrolled-to-bottom 960 × 640 macOS harness images; individual behavior limits remain documented in each chapter. This audit uses the workspace's exact `gpui-pre =0.3.5` (Zed revision [`d89e9c2`](https://github.com/zed-industries/zed/tree/d89e9c2124b2786a390c7a451c7488601b4da2e1)) and `gpui-kit =0.6.4`. GPUI paths below are under that revision's `crates/gpui/src/`; GPUI Kit's theme implementation is in the published [`gpui-component 0.6.4` source](https://docs.rs/crate/gpui-component/0.6.4/source/src/theme/mod.rs).

## Implemented chapter sequence

All six pages follow [`CHAPTER_TEMPLATE.md`](CHAPTER_TEMPLATE.md), use `{{#include}}` anchors from the compiling `examples/settings_screen` crate for Rust fences, and point to harness-generated images where the relevant screen state appears.

1. `elements/div-and-layout.md`: element tree, `Styled`, flex direction, and GPUI-to-Taffy grid/flex mapping; include `settings_screen_layout`.
2. `elements/size-and-scroll.md`: dimensions, padding/gap, overflow and an actual scroll container; include `settings_screen_scroll`.
3. `elements/text.md`: cascading font/color, line clamp, truncation, `StyledText` runs and UTF-8 byte lengths; include `settings_screen_text`, `settings_screen_text_truncate`, and `settings_screen_text_runs`.
4. `elements/images-and-svg.md`: supported raster and raw SVG paths; include `settings_screen_raster` and `settings_screen_media`.
5. `elements/conditional-lists.md`: Rust conditional child, iterator children, stable interactive row IDs; include `settings_screen_conditionals` and `settings_screen_list`.
6. `elements/settings-screen.md`: assemble the screen, theme initialization and verified toggle; include `settings_screen_main` and link back to the focused chapters.

The six topics share **one rendered example** with two harness baselines. The technique anchors are slices of `examples/settings_screen`, not separate unverifiable snippets. The macOS harness captures the top at `book/src/images/settings-screen.png`, calls `scroll_to_bottom()`, and captures the lower content at `book/src/images/settings-screen-scrolled.png`, both at 960 × 640 and scale 1.0. The library tests check the notification toggle and a wheel-driven scroll offset. On unsupported platforms, report compile/test results separately from macOS screenshot evidence. Run the book anchor checker, `mdbook build`, built-HTML check, spelling, and the relevant example tests after implementation; inspect any visual diff before accepting a new baseline.

## Open implementation checks

- The fixture compiles with a grid, bounded scroll area, visible wrapping and truncation, a two-run `StyledText`, raster and SVG media, and stable IDs. A library test checks a wheel-driven scroll offset, and a second harness image shows lower content. Alternate theme/scale captures are not yet present.

Their behavior is grounded in pinned source and compiling code. The reader-facing placeholder `Common mistakes` sections were removed; this notes file retains the report-level evidence gap.
